## Descripción
Sistema de inventarios para el manejo y control de bodegas, producción y ventas en microempresas. Muchas microempresas controlan su inventario con cuadernos u hojas de Excel, lo que dificulta saber qué entró, qué salió y quién lo movió. Este sistema registra qué se ingresó, cuándo y quién lo ingresó, y qué se vendió, a quién y por medio de qué vendedor, para calcular comisiones y mantener el control del material.

## Funcionalidades
- [ ] Registro de productos y categorías
- [ ] Entradas y salidas de inventario
- [ ] Registro de ventas (fecha, cliente, vendedor, medio de pago)
- [ ] Cálculo de comisiones por vendedor
- [ ] Manejo de varias bodegas
- [ ] Registro de producción (insumos → producto terminado)
- [ ] Alertas de stock mínimo
- [ ] Reportes básicos
- [ ] Multiempresa (cada cliente ve solo sus datos)
